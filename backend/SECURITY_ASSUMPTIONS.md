# Допущения безопасности

Рабочий пилот заблокирован CR-01…CR-05: нет схемы КШД, стабильных идентификаторов, доказательства утренней/вечерней отправки, протокола почты и корпоративного SSO.

## Fail-closed

- `AUTH_MODE=mock` в production не стартует. `password` разрешён только с `AUTH_PEPPER` длиннее 31 символа и не равным dev-перцу. `X-Dev-Subject` читается лишь при `mock` вне production. В режиме `password` сессия — HttpOnly cookie, в базе хранится только SHA-256 токена и scrypt-хеш пароля. `X-Role`, `role` и `actor` из запроса не назначают права. Роль берётся из `app_users`. Мутации с cookie требуют `X-Crew-Request: 1`.
- `SOURCE_ADAPTER` в production только `disabled`. `sample` — синтетические фикстуры, не Aviabit.
- `MAIL_ADAPTER` в production только `disabled`. `scripted` разрешён в тесте. Исход `X-Test-Mail-Outcome` вне scripted/не-production игнорируется. `delivery_unknown` не двигает базу и блокирует новый ключ.
- `POST /imports` сохраняет хэш, размер и очищенное имя. Байты файла не пишутся. Свой разбор XLSX читает только `xl/worksheets/sheet1.xml` и `xl/sharedStrings.xml`, методы ZIP 0 и 8, не больше 64 записей каталога. Распаковка ограничена 16 МиБ на запись и 24 МиБ суммарно, строка не больше 5001, колонка меньше 64, общих строк не больше 50 000. Выход за лимит — `422 IMPORT_LIMIT_EXCEEDED`, снимок не создаётся.
- Тело запроса не принимает `url` и `endpoint` для интеграций.
- Получатели письма должны быть в справочнике гостиницы. Домен `example.com` допускается только при `NODE_ENV=test`.

## Данные

- Письмо — plain text. Пол в письме не публикуется, он нужен только для пары DBL.
- Журнал не хранит текст письма и списки адресов. CSV экранирует ячейки, начинающиеся с `=`, `+`, `-`, `@`, табуляции и CR.
- Ошибки клиенту не содержат stack и персональных данных. SQL только с параметрами.

## Демо и рабочий UI

Демо (`npm run dev` в корне) остаётся на Zustand и `localStorage` ключа `crew-support-demo`. Это не production-контур: переключатель роли и локальные токены там допустимы только как прототип.

Рабочий интерфейс подключён к API:

- вход через `POST /api/v1/session`, профиль из `GET /api/v1/me`, роль из клиента не принимается;
- экипаж и письма не пишутся в `localStorage`;
- успех отправки не показывается, пока `GET /notifications/{id}` не вернул известный итог;
- nginx отдаёт собранный интерфейс с CSP, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy: no-referrer` и `Permissions-Policy` без камеры, микрофона и геолокации. HSTS нет: локальный контур без TLS.
