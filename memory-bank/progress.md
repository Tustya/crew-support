# Прогресс

Работает очередь, письма, история, настройки и импорт выгрузки.

Работает вход по почте и паролю для старшего и специалиста смены. Mock-заголовок остаётся только в API-тестах и не стартует в production.

В шапке, сайдбаре и журнале видно ФИО, должность подписью.

Не сделано: создание пользователей из интерфейса, смена пароля, второй фактор, живые Aviabit и SMTP.
